# Corruption2000

Браузерний «Симулятор корупціонера»: SimCity × The Sims, де бюджет родини складається лише з вкрадених коштів міста.

- `index.html` — основна версія в стилі SimCity 2000 (піксельна ізометрика, місто 80×80, камера, мінікарта).
- `cartoon/index.html` — ранча мультяшна версія, для порівняння.

Кожен файл самодостатній (HTML+JS+CSS), збірки нема. Запуск: відкрити `index.html` у браузері або ввімкнути GitHub Pages.

Усі події вигадані й спираються на загальні схеми з публічних розслідувань; реальних осіб у грі нема.
